# The engine types the SDK publishes in sdk/engine/include/wxl/engine/, one header per group.
#
# generate_engine.py compiles the group's headers of the client fork for x86 and x64, reads the
# layouts back and writes each type with its members at the fork's offsets, its size and offsets
# held by static_asserts and its layout hash. Nothing in sdk/engine/include/wxl/engine/ but
# support.hpp and check.hpp is written by hand.
#
#   group <stem> <fork header>[, <fork header>...]   [# what the header covers]
#     <fork type> [as <Name>]       a struct of the fork; Name defaults to the type with :: as _
#   witness <Name>.<member> <x86 address>
#                                   a function of Wow.exe 12340 that addresses the member: its
#                                   disassembly must hold the member's x86 offset (--binary)
#   comment-differs <Name>.<member> # why the fork's /* NNNN */ comment is not the x86 offset
#
# A type embedded by another must be listed (or be a template of support.hpp), or the member is
# bytes; a pointer to an unlisted type is a pointer to void. Appending a type changes no other
# type's hash; changing one changes the hash of every type that embeds it.
