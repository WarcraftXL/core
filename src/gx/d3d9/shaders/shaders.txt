# The runtime's own Direct3D 9 programs, compiled when it is built by wxl-core-d3d9-shaders
# (tools/shaders/compile_d3d9.cpp) into generated/d3d9_shaders.inc, one array of DWORDs each.
#
#   <name> <file> <profile> <entry> <constants> <samplers>
#
# <constants> is the float constant registers the program may read from the device (cA-cB, or -
# for none); <samplers> how many samplers it may use. A compiled program that reads any other
# register (its own `def` literals aside), or another sampler, fails the build.
